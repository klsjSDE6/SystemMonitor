# SystemMonitor 系统监控程序

基于 Python + `psutil` + Tkinter 实现的桌面系统监控工具，可实时显示：

- **CPU 占用率**（总占用 + 每核心占用）
- **磁盘使用率**（各分区容量 / 已用 / 百分比）
- **网络收发速率**（接收 / 发送 KB/s 或 MB/s）
- **磁盘 I/O 读写速率**（MB/s）
- 最近 **60 秒 CPU 使用率趋势折线图**

---

## 一、开发框架与技术

| 类别     | 技术                          | 版本要求      | 说明                                       |
| -------- | ----------------------------- | ------------- | ------------------------------------------ |
| 语言     | Python                        | ≥ 3.8         | 标准 CPython                               |
| 系统库   | [psutil](https://pypi.org/project/psutil/) | ≥ 5.9.0 | 跨平台系统进程 / 硬件信息采集              |
| GUI 框架 | [Tkinter](https://docs.python.org/3/library/tk.html) | （标准库） | Python 自带，无需额外安装，基于 Tcl/Tk 主题 |
| 图表绘制 | Tkinter Canvas                | （标准库）    | 自绘折线图，零第三方依赖                   |
| 样式     | ttk（clam 主题）              | （标准库）    | 深色主题统一界面风格                       |

> 选择理由：Tkinter 是 Python 内置 GUI，无需额外下载 Qt / wxWidgets 等重型依赖，非常适合教学型小项目；psutil 是采集系统信息的事实标准，跨 Windows / macOS / Linux 且 API 稳定。

## 二、主要功能

### 2.1 四项核心指标（每秒刷新）

| 面板       | 显示内容                                                          | 单位        |
| ---------- | ----------------------------------------------------------------- | ----------- |
| CPU 占用率 | 当前总占用率 + 核心数 + 前 4 个核心的占用率                        | %           |
| 网络收发   | 接收速率（↓）和发送速率（↑），超过 1024 KB/s 自动升级为 MB/s 显示  | KB/s / MB/s |
| 磁盘读写   | 磁盘顺序读取速率和写入速率                                         | MB/s        |
| 磁盘使用   | **所选分区**的占用率 + 已用容量 / 总容量                           | % + GB      |

### 2.2 附加特性

- **CPU 趋势折线图**：底部 Canvas 绘制最近 60 秒的 CPU 使用率曲线，带半透明填充
- **分区下拉切换**：支持在多个磁盘分区之间切换（C:/D:/…），磁盘使用率面板随之联动
- **采样周期可调**：默认 1000ms，可在 200–10000ms 之间任意调整
- **暂停 / 继续**：一键冻结实时数据，方便截图分析

## 三、用户操作手册

### 3.1 环境要求

- 操作系统：Windows 10/11（已测试）、macOS、Linux
- Python：3.8 及以上
- 网络无需常驻（网络速率基于累计差值，离线时显示 0）

### 3.2 安装与启动

```bash
# 1. 克隆仓库
git clone <仓库地址> SystemMonitor
cd SystemMonitor

# 2. 安装依赖（仅 psutil）
pip install -r requirements.txt

# 3. 启动程序
python gui.py
```

首次运行时，窗口顶部各面板会立刻刷新出实时数据。

### 3.4 操作步骤

| 操作           | 方法                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 启动 / 退出    | `python gui.py` 启动；关闭窗口或 Ctrl+C 退出                            |
| 暂停数据刷新   | 点击顶部 **「暂停」** 按钮，按钮文字变为「继续」                        |
| 切换磁盘分区   | 点击 **「磁盘分区」** 下拉菜单，即可查看 C:/D:/… 各分区使用率           |
| 调整采样速度   | 修改 **「采样周期」** 数字后回车，程序会用新周期开始下一次刷新           |

## 五、扩展说明

如需进一步增强功能，可考虑：

- 新增 **内存（RAM）使用率** 面板 → 用 `psutil.virtual_memory()`
- 把 Canvas 折线图换成 **matplotlib / pyqtgraph** 以支持多指标叠加
- 把数据导出到 **CSV** 文件做长期趋势分析（加一个"导出"按钮）
- 打包成单文件 `.exe` → `pyinstaller -F -w gui.py`
